# Portfolio

Personal portfolio site for Muhammad Hasham Hussain — a single-page site covering About, Projects, Skills, and Contact, built with Next.js and Tailwind CSS.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Structure

- `app/layout.tsx` — root layout and site metadata
- `app/page.tsx` — composes the page sections
- `components/` — `Nav`, `Hero`, `About`, `Projects`, `Skills`, `Contact`
